## Open Source

- [GLPI](https://glpi-project.org/) - Open-source IT asset management and helpdesk system. Used by MSPs and IT teams for ticketing, inventory, and asset tracking. Licensed under GPLv3. ([Read more](/details/glpi.md)) `Open Source` `Self-Hosted` `PSA` `ITAM` `Helpdesk`
- [MeshCentral](https://meshcentral.com/) - Open-source remote management and remote access platform. Self-hosted web-based solution for device control, terminal access, and file transfer. Licensed under Apache 2.0. ([Read more](/details/meshcentral.md)) `Open Source` `Self-Hosted` `Remote Access` `Web`
- [RustDesk](https://rustdesk.com/) - Open-source remote desktop application for remote access and support. Self-hostable relay server option available. Licensed under GPLv3. ([Read more](/details/rustdesk.md)) `Open Source` `Self-Hosted` `Remote Access` `Cross-Platform`
- [Tactical RMM](https://tacticalrmm.com/) - Open-source remote monitoring and management platform for MSPs. Self-hosted with PowerShell-based agents and a web dashboard. Licensed under AGPLv3. ([Read more](/details/tactical-rmm.md)) `Open Source` `Self-Hosted` `RMM` `PowerShell`

## Remote Access

- [GoTo Resolve](https://www.goto.com/resolve) - Remote access and support software with IT management features. Includes unattended remote access, ticketing, and device management. Offers a free plan and paid tiers. ([Read more](/details/goto-resolve.md)) `Freemium` `Remote Access` `API` `Support`
- [Splashtop Enterprise](https://www.splashtop.com/enterprise) - Remote access and remote support solution for MSPs and IT teams. ## RMM Platforms

- [Action1](https://www.action1.com/) - Cloud-native RMM platform for patch management and remote endpoint control. Offers a free tier for up to a limited number of endpoints, with paid plans for larger deployments. ([Read more](/details/action1.md)) `Freemium` `API` `RMM` `Patch Management`
- [Atera](https://www.atera.com/) - All-in-one RMM and PSA platform for MSPs, priced per technician rather than per endpoint. Includes remote access, patch management, and billing features. Cloud-based with paid subscription plans. ([Read more](/details/atera.md)) `Paid` `API` `RMM` `PSA` `Per Technician`
- [Level](https://level.io/) - Modern RMM platform for MSPs and IT teams with remote access, scripting, and automation. Cloud-based with a paid subscription model and no per-endpoint pricing on some plans. ([Read more](/details/level.md)) `Paid` `API` `RMM` `Cloud`
- [N-able N-central](https://www.n-able.com/n-central) - RMM platform designed for MSPs and internal IT teams. Provides monitoring, automation, patch management, and remote access. Commercial paid product with cloud deployment. ([Read more](/details/n-able-n-central.md)) `Paid` `Enterprise` `API` `RMM`
- [NinjaOne](https://ninjaone.com/) - Cloud-based RMM and endpoint management platform for MSPs and IT departments. Offers patch management, remote control, scripting, and backup integrations. Pricing is subscription-based, typically quoted per endpoint. ([Read more](/details/ninjaone.md)) `Paid` `API` `RMM` `Endpoint Management`
- [Pulseway](https://www.pulseway.com/) - RMM and mobile-first IT management platform for MSPs and IT teams. Provides real-time monitoring, patch management, and remote control via mobile and desktop. Paid subscription service. ([Read more](/details/pulseway.md)) `Paid` `API` `RMM` `Mobile`
- [SuperOps](https://www.superops.com/) - Cloud-based RMM and PSA platform for MSPs with project management and documentation. Includes AI-powered features and automation. Offered as a paid subscription. ([Read more](/details/superops.md)) `Paid` `API` `AI-Powered` `RMM` `PSA`
- [Syncro](https://www.syncromsp.com/) - Combined RMM, PSA, and remote access platform for MSPs. Includes ticketing, invoicing, and endpoint management in a single cloud interface. Paid subscription model. ([Read more](/details/syncro.md)) `Paid` `API` `RMM` `PSA` `Remote Access`

## Security for MSPs

- [Huntress](https://www.huntress.com/) - Managed security platform for MSPs focusing on endpoint detection and response. Includes threat hunting, anti-persistence, and remediation. Paid subscription service. ([Read more](/details/huntress.md)) `Paid` `Security` `EDR` `MSP` `API`
- [Malwarebytes Nebula](https://www.malwarebytes.com/business) - Cloud-based endpoint protection for MSPs and businesses. Provides antivirus, anti-malware, and remediation through a centralized console. Paid commercial product.
